
test_create_courier.py проверяет ручку создания курьера: позитивный сценарий (курьера можно создать, используются валидные данные) и негативные сценарии (нельзя создать две одинаковые учетные записи, нельзя создать курьера без логина или пароля, нельзя создать курьера с уже существующим логином).

test_create_order.py проверяет ручку создания заказа: можно заказать самокат, указав один из цетов - "BLACK" или "GREY", выбрав оба цвета, не указывая цвет.

test_get_order_list.py проверяет ручку получения списка заказов: возвращаемое значение - список.

test_login_courier.py проверяет ручку логина курьера: позитивный сценарий (зарегистрированный курьер может войти в свою учетную запись) и негативные сценарии (нельзя войти в учетную запись, если: не заполнить логин или пароль, ввести неправильный логин или пароль, ввести несуществующие логин и пароль).
